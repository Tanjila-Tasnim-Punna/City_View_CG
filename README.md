# City View Simulation using OpenGL

## Overview

This project is a Computer Graphics simulation developed using OpenGL and GLUT in C++. It creates an animated city environment featuring buildings, roads, vehicles, a moving metro train, clouds, trees, and other urban elements.

The project demonstrates the use of basic OpenGL primitives, transformations, animation techniques, and 2D graphics rendering.

## Features

* Animated Metro Train
* Moving Cars
* Moving Clouds
* Buildings with Detailed Windows
* Roads and Bridge Structure
* Trees and Street Environment
* Sun with Rays
* Real-time Animation using GLUT

## Technologies Used

* C++
* OpenGL
* GLUT (OpenGL Utility Toolkit)

## Project Components

### City Infrastructure

* Multiple buildings with architectural details
* Roads and road markings
* Bridge structure
* Street lights

### Animated Objects

* Metro train
* Cars
* Clouds

### Natural Elements

* Trees
* Sun

## How to Run

### Requirements

* C++ Compiler (GCC/MinGW)
* OpenGL Library
* GLUT Library

### Compile

```bash
g++ city_view.cpp -o city_view -lopengl32 -lglu32 -lfreeglut
```

### Run

```bash
./city_view
```
